# IPL Ticket Booking Website

A web-based IPL ticket booking project developed as part of Web Application coursework. This repository contains two activities demonstrating frontend development using HTML, CSS, JavaScript, React, and Supabase.

```text

│   └── images/
│
├── Activity-2/
│   └── IPL-React-Booking/
│       ├── src/
│       ├── public/
│       ├── package.json
│       └── ...
│
└── README.md
```

## Activity 1 – IPL Ticket Booking Website

Developed using:
- HTML
- CSS
- JavaScript

Features:
- IPL matches and team information
- Ticket booking page
- Responsive website design
- Interactive elements using JavaScript

## Activity 2 – IPL React Booking

Developed using:
- React
- Vite
- Supabase

Features:
- Match listing
- Ticket booking functionality
- Supabase database integration
- Realtime match data updates

## How to Run

### Activity 1

Open `Activity-1/index.html` in a browser or use Live Server in VS Code.

### Activity 2

1. Navigate to `Activity-2/IPL-React-Booking`.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL shown in the terminal.
